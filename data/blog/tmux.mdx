## Commands
- `tmux ls`: list all the sessions


## Shortcuts (`Ctrl + B`)
- Command mode: `:`
    - list all the shortcuts: `list-keys`
    - list all the commands: `list-commands`
- New window: `c` 
- Previous/Next window: `p/n`
- Rename window: `,`

### Pane
- Left/Right pane: `<- / ->`
- Kill pane: `x`
